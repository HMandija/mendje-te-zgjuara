Konfigurimi: [Cloudflare deployment](docs/CLOUDFLARE-DEPLOY.md).

Administrimi është në `/admin`, pa link në faqen kryesore. Konfigurimi dhe kufijtë e verifikimit email janë në [docs/ADMIN.md](docs/ADMIN.md).
